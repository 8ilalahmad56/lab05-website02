# lab05-website02
Prompt: Create a Single-Screen CV Website with No Scrolling

Build a modern, professional, fully responsive single-page CV/Resume website where scrolling is completely disabled. The entire website must fit within the visible screen (100vh) without any vertical or horizontal scrolling.

1. Design and Layout
Create a premium, clean, minimal, and professional CV design.
Use a modern color palette such as navy blue, white, light gray, and a subtle accent color.
Use professional typography, balanced spacing, and clear visual hierarchy.
Make the website look impressive to recruiters and employers.
Use CSS Flexbox and Grid to organize the content efficiently.
Fit all essential CV information into one screen without making text too small.
2. No-Scrolling Requirement
The entire website must fit within the browser viewport at all times.
Set the main layout to height: 100vh or height: 100dvh.
Disable page scrolling using overflow: hidden on the appropriate page containers.
Prevent both vertical and horizontal scrolling.
Do not create multiple scrollable sections, internal scrolling panels, or long-page layouts.
Do not use navigation links that scroll to other sections.
Ensure the complete CV is visible immediately after the page loads.
Optimize the layout for common laptop and desktop screen sizes.
On smaller screens, reorganize content into a compact layout while maintaining the no-scrolling requirement.
Never hide important CV content just to make the layout fit.
3. Screen Layout

Divide the screen into three main areas:

Left Sidebar — Personal Profile
Professional profile picture.
Full name.
Professional title.
Short professional summary.
Email address and phone number, if provided.
Location, if provided.
LinkedIn and GitHub links, where applicable.
Center Area — Professional Background
Work experience with job titles, companies, dates, and key achievements.
Education with qualifications and institutions.
Selected projects with short descriptions.
Certifications or awards, if applicable.
Right Sidebar — Skills and Additional Information
Technical skills.
Soft skills.
Tools and technologies.
Languages.
Key achievements or other relevant information.

Use compact cards, short bullet points, subtle dividers, and consistent spacing to present information clearly.

4. Interactive Elements
Add a functional “Download CV” button.
Add a “Contact Me” button that opens an email link or contact destination.
Make LinkedIn, GitHub, and portfolio links clickable.
Use subtle hover effects on buttons and links.
Do not add a sticky navigation bar or navigation menu that requires scrolling.
Ensure all buttons and links work correctly.
5. Responsive Design
On desktop, use a three-column layout.
On laptops, reduce gaps, padding, and card sizes intelligently.
On tablets and mobile screens, use a compact responsive arrangement that prioritizes the most important information.
Use responsive font sizes with CSS clamp().
Ensure the content never overflows the viewport.
Do not solve mobile overflow by making the text unreadably small or cutting off important sections.
6. Technical Requirements
Use clean, maintainable HTML, CSS, and JavaScript, or the framework requested by the user.
Use semantic HTML and accessible color contrast.
Disable document scrolling and prevent accidental overflow.
Use optimized images and lightweight animations.
Include appropriate page metadata and an SEO-friendly title.
Make the CV easy to update using clearly organized content.
Use only the personal information provided; do not invent qualifications, experience, or achievements.
7. Final Instructions

Create the complete working website, not just a mockup.

The final result must be a one-screen CV dashboard with zero page scrolling, a professional layout, readable text, functional buttons, and all essential CV details visible at once.

Test the website at different viewport sizes. If the content does not fit, rearrange the layout and shorten descriptions without removing essential information. Do not use scrollbars as a workaround.
